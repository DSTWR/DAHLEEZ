# دهليز | DAHLEEZ

**وكالة أخبار عربية مستقلة**  
**الحقيقة أولاً، والخبر كما هو.**

دهليز مشروع وكالة إخبارية رقمية عربية، يهدف إلى تغطية شاملة ودقيقة وسريعة، مع فصل واضح بين الخبر والرأي، وإظهار المصدر ووقت النشر والتحديث.

## حالة المشروع
مرحلة التأسيس وبناء النواة. الواجهة الحالية تعريفية وتجريبية، ولا تحتوي على أخبار حية أو نظام نشر. لم يتم تفعيل النشر العام أو ربط حسابات التواصل.

## الهوية
- الاسم: دهليز | DAHLEEZ
- الشخصية: مستقلة، مهنية، عربية، عالمية.
- الألوان: كحلي عميق، ذهبي هادئ، عاجي، وأحمر للتنبيهات المؤكدة فقط.
- اللغة الأساسية: العربية من اليمين إلى اليسار.
- العبارة: الحقيقة أولاً، والخبر كما هو.

## المبادئ التحريرية
1. لا خبر بلا مصدر قابل للفحص.
2. الفصل بين الخبر والتحليل والرأي.
3. إظهار وقت النشر والتحديث.
4. التحقق من الأخبار العاجلة من مصدر أولي أو مصدرين مستقلين كلما أمكن.
5. احترام حقوق الصور والمواد المنشورة.
6. التصحيح الواضح والعلني عند وقوع خطأ.

## بنية المشروع
- `index.html`: واجهة الموقع.
- `assets/css/style.css`: التصميم المتجاوب.
- `assets/js/app.js`: التفاعلات.
- `assets/brand/`: ملفات الهوية SVG.
- `docs/`: السياسة التحريرية وخطة الإطلاق.

## شروط الإطلاق
لا يتم إطلاق الموقع أو تشغيل النشر الآلي قبل مراجعة المالك واعتماد المصادر وآلية التحقق. راجع `docs/LAUNCH-CHECKLIST.md`.
