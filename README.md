# دهليز | DAHLEEZ

**وكالة أخبار عربية مستقلة تعمل على مدار الساعة.**

دهليز مشروع لبناء غرفة أخبار رقمية: رصد المصادر، التحقق والتحرير، إدارة المحتوى، النشر متعدد القنوات، والتحليلات.

## المبادئ التحريرية
- الدقة قبل السرعة، مع إظهار المصدر ووقت النشر.
- عدم نشر الادعاءات غير المؤكدة كحقائق.
- الفصل بين الخبر والتحليل والرأي.
- تصحيح الأخطاء بوضوح والاحتفاظ بسجل للتحديثات.
- احترام حقوق النشر والتراخيص وعدم نسخ مواد الغير.

## مكونات النظام
1. موقع إخباري عربي متجاوب (RTL).
2. لوحة إدارة وغرفة أخبار.
3. مجمّع مصادر RSS وواجهات الأخبار المسموح بها.
4. مسار تحقق وتحرير بمساعدة الذكاء الاصطناعي.
5. جدولة ونشر عبر واجهات المنصات الرسمية.
6. مراقبة التشغيل وتقارير الأداء والتنبيهات.

## قواعد الأمان
- لا تُخزَّن مفاتيح API أو كلمات المرور في المستودع.
- تستخدم أسرار GitHub أو متغيرات البيئة في خدمات التشغيل.
- الأخبار الحساسة والعاجلة غير المؤكدة تتطلب مراجعة بشرية.
- لا يتم تجاوز حدود الخدمات أو شروط المنصات.

## حالة المشروع
مرحلة التأسيس. لم يتم تفعيل النشر الآلي أو ربط أي حسابات اجتماعية بعد.

## التقنية
سيتم اعتماد الخدمات بعد التحقق من حدود خططها المجانية وشروطها، ولن يُفترض أن أي خدمة مجانية بلا حدود.
