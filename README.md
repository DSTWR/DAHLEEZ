# دهليز | DAHLEEZ

**وكالة أخبار عربية مستقلة**  
**الحقيقة أولاً، والخبر كما هو.**

دهليز منصة إخبارية عربية مستقلة قيد التطوير. تفصل المنصة بين الرصد والتحقق والتحرير والنشر، ولا تظهر المواد الواردة من الخلاصات للقراء قبل اعتماد محرر.

## الهوية
- الاسم: دهليز | DAHLEEZ
- الشخصية: مستقلة، مهنية، عربية، عالمية.
- الألوان: كحلي عميق، ذهبي هادئ، عاجي، وأحمر للتنبيهات المؤكدة فقط.
- اللغة الأساسية: العربية من اليمين إلى اليسار.
- العبارة: الحقيقة أولاً، والخبر كما هو.

## البنية التقنية الحالية
- الموقع الثابت: Cloudflare Workers Static Assets من مجلد public/.
- الخلفية: Cloudflare Worker في backend/src/worker.js.
- قاعدة البيانات: Cloudflare D1، مربوطة بالاسم DB.
- جمع الأخبار: ثلاثة مصادر RSS عربية مهيأة مع تشغيل مجدول كل 15 دقيقة.
- التحرير: لوحة داخلية على /admin.html مع رمز ADMIN_TOKEN.
- النشر: لا يظهر سوى approved في واجهة الأخبار وواجهة API. كل مادة مستوردة تبدأ pending.
- CI/CD: GitHub Actions للتحقق والنشر إلى Cloudflare.

## صفحات ووظائف الموقع
- /: الصفحة الرئيسية، آخر الأخبار المعتمدة، التصنيفات والبحث.
- /story.html?id=STORY_ID: صفحة تفاصيل الخبر ومصدره.
- /admin.html: غرفة التحرير الخاصة، غير مفهرسة.
- /api/health: حالة الخدمة.
- /api/stories: الأخبار المنشورة فقط، مع دعم التصنيف والبحث والتصفح.
- /api/stories?id=...: تفاصيل مادة معتمدة فقط.
- /robots.txt و/sitemap.xml: إرشادات الفهرسة وخريطة الموقع.

## التشغيل والتطوير
من مجلد backend/ شغّل wrangler deploy --dry-run للتحقق ثم wrangler deploy للنشر.
يتطلب النشر CLOUDFLARE_API_TOKEN وCLOUDFLARE_ACCOUNT_ID في GitHub Secrets. لا تضع أي سر في المستودع.

## مبادئ لا نتجاوزها
1. لا خبر بلا مصدر قابل للفحص.
2. لا نشر تلقائي لمادة غير مراجعة.
3. الفصل بين الخبر والتحليل والرأي.
4. إظهار المصدر ووقت النشر والتحديث عندما يتوفران.
5. احترام حقوق الصور والمواد المنشورة.
6. تصحيح الأخطاء بوضوح.
7. لا نعلن أن الخدمة أو المصادر تعمل قبل التحقق من ذلك.

## ملاحظات النطاق
العنوان الحالي هو نطاق workers.dev الافتراضي. النطاق المخصص يحتاج نطاقاً يملكه صاحب المشروع ويضيفه إلى Cloudflare DNS. لا يوجد نطاق مملوك ومتاح في حساب Cloudflare الذي جرى فحصه حالياً.
