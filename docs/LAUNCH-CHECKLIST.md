# قائمة ما قبل الإطلاق

- [ ] اعتماد الشعار النهائي وملفات الهوية.
- [ ] اختيار اسم النطاق وربطه بالموقع.
- [ ] تحديد مصادر الرصد وحقوق إعادة الاستخدام.
- [ ] إعداد سجل مصدر ووقت تحقق لكل مادة.
- [ ] بناء لوحة تحرير داخلية وصلاحيات دخول.
- [ ] تفعيل مراجعة بشرية للأخبار الحساسة والعاجلة.
- [ ] إعداد سياسة الخصوصية وشروط الاستخدام وبيانات التواصل.
- [ ] اختبار الهاتف والسرعة وإمكانية الوصول.
- [ ] اختبار النسخ الاحتياطي وسجل التصحيحات.
- [ ] موافقة المالك الصريحة قبل النشر العام.

## حدود النواة الحالية
الواجهة قالب موقع فقط. لا يوجد نظام إدارة محتوى أو جمع أخبار حي أو حسابات مستخدمين أو نشر اجتماعي أو تنبيهات حقيقية. لا توصف بأنها وكالة تعمل 24/7 قبل بناء هذه الأنظمة واختبارها.
